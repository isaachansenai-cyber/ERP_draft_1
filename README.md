# Meats Around the World ERP (MVP pilot)

Internal restaurant ERP for three locations (Provo, Spanish Fork, Salt Lake City): staff POS, kitchen/pickup, recipe-based inventory, purchasing, supplier invoices, planning (MRP/EOQ), schedules and reporting. React + TypeScript + Vite (GitHub Pages) with Supabase Auth, Postgres, RLS and transactional RPCs.

**Status:** specification and data package only. No application code yet.
